# freeDOM Scriptoria DOM Playground patch

Copy the contents of this ZIP into the root of the `@blcklab/freedom` repository. It replaces the previous static module Playground with interactive DOM examples.

The new examples live under `.scriptoria/playground/dom/`, so older static example folders are ignored by the new manifest and cannot be rediscovered accidentally.

Requires the Scriptoria release that includes the first-party `dom` adapter and the v0.16 Playground schema.
